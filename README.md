# AreaBOX

Каркас приложения для расчёта гофрокоробов на Vue 3, TypeScript и Vite.

## Статус

Версия 0.1: оболочка, пять маршрутов и форма параметров с базовой валидацией.
Расчётное ядро, паспорта машин, раскладка и экспорт ещё не перенесены из исходного HTML.
Схема на главном экране — иллюстрация, а не расчётный чертёж.

## Локальный запуск

Node.js 22.12 или новее.

```sh
npm ci
npm run dev
```

```sh
npm run build
npm run preview
```

## Структура

- `src/components` — компоненты интерфейса.
- `src/views` — страницы.
- `src/domain` — типы и будущие чистые расчётные функции; размеры в мм, площади в м².
- `src/data` — каталоги и будущие паспорта оборудования.
- `src/composables` — состояние и сценарии приложения.
- `docs` — архитектура и план переноса.

## GitHub Pages

В Settings → Pages выбрать Source: **GitHub Actions**.
Workflow `.github/workflows/pages.yml` проверяет типы, собирает приложение и публикует `dist` при push в `main`.
Pull request выполняет только проверку сборки.
Относительный `base` и hash-маршрутизация поддерживают размещение в подпапке репозитория и обновление страницы.
