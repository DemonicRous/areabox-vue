# Интерфейс AreaBOX

Режим: Operate. Параметры слева, результат справа; на мобильном устройстве — вертикально.
Главное меню: «Короб» и «Оборудование». Виды результата переключаются внутри рабочей области.
Диагностика раскрывается под результатом. Старые адреса перенаправляются на соответствующие виды.
Tailwind CSS с официальным Vite-плагином. Семантические CSS-переменные задают две темы.
Светлая: нейтральный фон, белые поверхности, зелёный акцент. Тёмная: графитовые поверхности, светлый текст, мягкий зелёный акцент.
Иконки Heroicons outline. Переключатель темы имеет доступные названия и aria-pressed.
Основные элементы управления не ниже 44 px. Заголовки 18 px, текст 14 px, подписи 12 px.
Без hero, нумерации блоков, слоганов, демонстрационного чертежа и roadmap.
Пустые состояния обозначают неподключённые функции одной строкой.
Сохранённая тема применяется до запуска Vue; при отсутствии настройки — системная.
