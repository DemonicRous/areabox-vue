# Основа AreaBOX

Первый этап по запросу пользователя: каркас Vue 3 и GitHub Pages, без переноса калькулятора.

Выбор реализации: Vue 3 Composition API, TypeScript, Vite, Vue Router с hash history.
Приложение статическое, без сервера и авторизации. Развёртывание через GitHub Actions.

Расчётное ядро размещается в `src/domain` без зависимостей от DOM и Vue.
Площади переводятся в м² на границе расчёта; форматирование не изменяет исходные значения.
Проверка пригодности оборудования должна быть общей для рекомендаций, маршрута и диагностики.
Редактор паспортов должен работать с черновиком и применять изменения только после сохранения.

Порядок переноса:

1. Входные параметры, геометрия и контрольные примеры из HTML.
2. Паспорта, проверка панелей между бигами и соединительного клапана.
3. Раскладка с настраиваемыми полями и ограничениями числа мест.
4. Маршрут, диагностика, SVG/DXF и импорт/экспорт JSON.

До переноса правила машин и производственные данные не считаются подтверждёнными.
Исходный HTML не включается в публичный репозиторий автоматически.
